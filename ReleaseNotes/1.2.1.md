Bouncer 1.2.1 fixes a crash on Linux.

## Fixed

- **Segmentation fault on Linux and WSL with deeply nested code.** The Linux release binaries are static musl builds, and musl gives new threads a 128 KiB stack. Parsing deeply nested code, such as TypeScript with a few dozen levels of nested callbacks or generated Swift, could overflow that stack and crash `review`, `check`, `baseline update` and `bouncer mcp`. Analysis now runs on threads with a 64 MiB stack on every platform. That space is reserved rather than allocated, so it costs no memory until it's used. The crash also happened in 1.1.0; it wasn't caused by 1.2's parallel analysis. macOS gives these threads a larger stack and wasn't affected.
