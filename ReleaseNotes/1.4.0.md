Bouncer 1.4.0 lets you, or a coding agent, look up any rule from the command line, and adds a man page.

## Highlights

- **`bouncer rules`.** Lists every built-in rule, grouped by its rule catalog section, with its default severity. `bouncer rules <id>`, such as `bouncer rules long-function`, explains one rule: what it checks, why it matters, its parameters, its fix cost, and how to configure it in `.bouncer` or suppress a single finding. The text is the same as the MCP server's `explain_rule` tool returns, so an agent without MCP can look up a rule it doesn't recognize. A mistyped ID exits with an error and suggests the closest rules.
- **Man page.** `man bouncer` documents every command and flag. It's generated from the CLI's own help, so it matches `--help`. It ships in the macOS and Linux archives, and both Homebrew and the install script put it where `man` finds it: the install script copies it to the `share/man/man1` folder next to the folder it installs `bouncer` into (by default `~/.local/share/man/man1`). Windows has no `man`, so its archive has no man page.
